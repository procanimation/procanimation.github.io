1. The Fundamental Recurrence Relation

The Mandelbrot set $M$ is defined on the complex plane $\mathbb{C}$. Unlike Julia sets, which fix a parameter $c$ and vary the initial seed $z_0$, the Mandelbrot set always initializes from the critical point $z_0 = 0$ (the unique zero of the derivative $f'(z) = 2z$):

The Quadratic Recurrence Mapping
$$z_0 = 0$$ $$z_{n+1} = z_n^2 + c$$ $$M = \left\{ c \in \mathbb{C} : \sup_{n \in \mathbb{N}} |z_n| \le 2 \right\}$$

Expanding into Cartesian coordinates where $z_n = x_n + i y_n$ and $c = c_r + i c_i$:

$$x_{n+1} = x_n^2 - y_n^2 + c_r$$ $$y_{n+1} = 2 x_n y_n + c_i$$

2. Rigorous Escape Radius Theorem ($|z| > 2$)

Why is the bailout radius exactly $2$? We can prove this rigorously via the triangle inequality:

Escape Radius Lower Bound Proof
$$\text{Suppose } |z_n| = R > 2 \text{ and } R \ge |c|.$$ $$\text{By reverse triangle inequality: } |z_{n+1}| = |z_n^2 + c| \ge |z_n|^2 - |c| = R^2 - |c|.$$ $$\text{Since } R > 2 \text{ and } R \ge |c|: \quad R^2 - |c| \ge R^2 - R = R(R - 1).$$ $$\text{Let } \alpha = R - 1 > 1. \implies |z_{n+1}| \ge \alpha |z_n|.$$ $$\text{By induction: } |z_{n+k}| \ge \alpha^k |z_n| \xrightarrow{k \to \infty} \infty.$$

Hence, once an orbit crosses $|z_n| > 2$, divergence to infinity is mathematically inevitable.

3. Continuous Potential & Smooth Logarithmic Shading

Discrete escape-time algorithms color a pixel based solely on the integer iteration count $k$. This produces conspicuous color banding. To achieve buttery smooth gradients, we treat the escape field as an electrostatic potential generated by a charged Mandelbrot conductor:

$$\nu(z) = k + 1 - \frac{\ln(\ln|z_{k}|)}{\ln 2}$$

Because $|z_k|$ roughly doubles on every step past the escape boundary ($|z_{k+1}| \approx |z_k|^2$), the double logarithm $\ln(\ln|z_k|)$ grows linearly with $k$. Subtracting it normalizes the discrete steps into a $C^\infty$ continuous manifold.

4. Shishikura's Theorem: Boundary Dimension is Exactly 2

A classic question in complex dynamics was: What is the fractal dimension of the boundary $\partial M$?

In 1998, mathematician Mitsuhiro Shishikura proved in the Annals of Mathematics that:

$$\dim_{\text{Hausdorff}}(\partial M) = 2$$

While the set itself encloses a finite 2D area of approximately $1.50659177$, its boundary has zero two-dimensional Lebesgue measure, yet is so infinitely tortuous and folded that its Hausdorff dimension attains the maximum possible value for a subset of the plane.

// Procanimation Studio — High-Performance Continuous Potential Mandelbrot
function renderMandelbrotPixel(cRe, cIm, maxIter) {
  // Main Cardioid & Period-2 Bulb early bailout optimization
  const crMinusQuarter = cRe - 0.25;
  const q = crMinusQuarter * crMinusQuarter + cIm * cIm;
  if (q * (q + crMinusQuarter) <= 0.25 * cIm * cIm) return { inSet: true, smooth: maxIter };
  if ((cRe + 1) * (cRe + 1) + cIm * cIm <= 0.0625) return { inSet: true, smooth: maxIter };

  let zRe = 0.0, zIm = 0.0, iter = 0;
  while (zRe * zRe + zIm * zIm <= 4.0 && iter < maxIter) {
    const nextRe = zRe * zRe - zIm * zIm + cRe;
    zIm = 2.0 * zRe * zIm + cIm;
    zRe = nextRe;
    iter++;
  }

  if (iter === maxIter) return { inSet: true, smooth: maxIter };

  // Smooth continuous logarithmic index
  const modZ = Math.sqrt(zRe * zRe + zIm * zIm);
  const smooth = iter + 1 - Math.log(Math.max(1, Math.log(modZ))) / Math.log(2);
  return { inSet: false, smooth: smooth };
}
