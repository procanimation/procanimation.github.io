How does a machine make sense of the universe? An image of a galaxy is not an object to a computer—it is a matrix of pixel brightness values. A patient in an ICU is a collection of blood pressure, oxygen saturation, and heart rate measurements. An English prompt typed into ChatGPT is converted into a sequence of numbers. To every machine learning algorithm and large language model in existence, reality is translated into a single geometric object: The Vector.

The Machine Learning Architecture

Vector Spaces & Euclidean Norm

$$\mathbf{v} \in \mathbb{R}^n, \quad \|\mathbf{v}\|_2 = \sqrt{\sum_{i=1}^n v_i^2}$$. An ordered array of numbers representing a point or directional arrow in multidimensional space. Unit vectors ($$\mathbf{\hat{v}} = \mathbf{v} / \|\mathbf{v}\|$$) isolate pure orientation without magnitude bias.

The Dot Product & Cosine Similarity

$$\mathbf{a} \cdot \mathbf{b} = \sum a_i b_i = \|\mathbf{a}\| \|\mathbf{b}\| \cos\theta$$. If vectors are nouns, the dot product is the verb. When $$\theta = 90^\circ$$, the dot product vanishes, signifying orthogonal, uncorrelated features. Normalized, it yields Cosine Similarity ($$\cos\theta \in [-1, 1]$$), the foundation of vector search and LLM embeddings.

The Linear Model & Residuals

$$\hat{y} = \mathbf{w} \cdot \mathbf{x} + b, \quad \epsilon_i = y_i - \hat{y}_i$$. Predictions are generated by projecting input features against trainable weights $$\mathbf{w}$$ plus a baseline bias threshold $$b$$. The vertical distance between predictions and ground truth defines the residual error.

Convex Loss Bowls & Gradient Descent

$$J(\mathbf{w}, b) = \frac{1}{2n}\sum \epsilon_i^2, \quad \mathbf{w}_{t+1} = \mathbf{w}_t - \alpha \nabla_{\mathbf{w}} J$$. Mean Squared Error shapes parameter space into a strictly convex 3D paraboloid with zero local traps. Gradient descent computes the uphill slope ($$\nabla J$$) and steps downhill by learning rate $$\alpha$$.
