# Procanimation World — Official Portfolio Website 🎬✨

> **Live Website**: [https://procanimation.github.io](https://procanimation.github.io)

This is the public portfolio and creative coding showcase website for **Procanimation World**, built with **Jekyll** and **Sass (SCSS)** and hosted on **GitHub Pages**.

---

## 🌟 Highlights
* **Interactive Hero Simulation**: Real-time gravitational particle wave canvas that reacts to mouse interactions.
* **YouTube Journey Showcase**: Video cards, duration badges, and channel banner integration.
* **Creative Coding Ecosystem**: Live interactive filterable showcase of `planetary-motion`, `patterns`, `science-stuff`, `mathematics-stuff`, `twelve-bead`, `pictography`, and `antqueue`.
* **Zero Recurring Cost Studio**: Complete breakdown of the automated local video production pipeline.

---

## 🛠️ Built With
* [Jekyll](https://jekyllrb.com/) — Fast static site generator
* [Sass / SCSS](https://sass-lang.com/) — Modular component stylesheets
* [GitHub Pages](https://pages.github.com/) — Automated cloud deployment
* Pure Vanilla JavaScript — High-performance interactive HTML5 canvas physics
